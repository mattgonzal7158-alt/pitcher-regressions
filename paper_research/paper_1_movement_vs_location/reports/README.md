# Paper 1 Reports

Read these in this order:

1. `paper_results_summary.md` - paper-ready findings and interpretation.
2. `paper_tables_and_figures.md` - assembled descriptive tables, regression tables, robustness tables, and figure list.
3. `main_regression_results.md` - full main regression output.
4. `robustness_checks.md` - weighted, standardized, influence-trimmed, pitch-type, and batter-side robustness checks.
5. `regression_diagnostics.md` - VIF, heteroskedasticity, normality, autocorrelation, and influence diagnostics.
6. `regression_dataset_summary.md` - dataset construction notes, row counts, missingness, and sample filters.
